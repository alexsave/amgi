## amgi audio fill settings

These are the same credentials you sign in to the amgi web app with, plus the project's public settings.

`supabase_url`
The project URL, for example `https://xxxxxxxx.supabase.co`.
Find it in the amgi web app's build config (`NEXT_PUBLIC_SUPABASE_URL`), or ask whoever runs your amgi deployment.

`supabase_anon_key`
The project's anon/publishable key (`NEXT_PUBLIC_SUPABASE_ANON_KEY`).
This is a public key meant to be embedded in a client, not a secret; it identifies the project, not you.

`email` and `password`
Your amgi account.
Stored in this add-on's own config file, in plain text, the same way `plusaudio/.env` stores an OpenAI key: readable to anything with access to your Anki profile folder, and to nothing else.
The add-on signs in with these to get a short-lived access token, and refreshes it on its own for a run that outlasts one.

Every clip is generated by the same `cards` edge function and the same quota your account already has in the web app; this add-on does not bypass either.
